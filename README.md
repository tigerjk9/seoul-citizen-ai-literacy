# AI를 읽는 힘, 인간을 생각하는 시간

서울시민대학교 AI 리터러시 강연의 공개 강연 자료 사이트입니다. 부제는 "빼고, 더하고, 곱하는 AI 리터러시"이고, 강연자는 김진관(닷커넥터)입니다.

- 강연 자료: https://tigerjk9.github.io/seoul-citizen-ai-literacy/ (V10 슬라이드 88장, 교안 PDF)
- 참고자료: https://tigerjk9.github.io/seoul-citizen-ai-literacy/research.html
- 블로그 자료실: https://tigerjk9.github.io/lectures/seoul-citizen-ai-literacy/ (발표 대본, 비밀번호 보호)

"AI는 거들 뿐, 생각의 주인은 나입니다"를 주장으로 삼아 디지털 기반 아날로그 수업, 통념을 깨는 학습과학, 지식교육과 역량교육의 조화, 그레그 니마이어의 −AI·+AI·×AI와 서로 가르치기를 하나로 엮었습니다.

## 구성

| 경로 | 내용 |
|------|------|
| `index.html` | 강연 자료 화면(슬라이드 갤러리, 교안 내려받기, QR) |
| `research.html` | 참고문헌과 관련 자료 |
| `assets/v10/` | V10 슬라이드와 썸네일(webp) |
| `assets/og-image.jpg` | 공유 미리보기 이미지. 블로그 자료실 카드도 이 파일을 씁니다 |
| `pdf/` | V10 교안 PDF |

`main` 브랜치를 GitHub Pages로 그대로 게시합니다(빌드 없음, `.nojekyll`). 원고·대본·편집 소스는 비공개 저장소에서 관리합니다.
